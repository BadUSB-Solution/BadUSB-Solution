## 기능 1 — Qt i18n 전체 UI 언어 전환

### 동작 방식

- **소스 언어**: 한국어 (기본값, 별도 .qm 불필요)
- **영어**: `en.ts` → `en.qm` 번역 파일로 제공
- **전환 시점**: 설정 저장 후 앱 재시작 시 적용

### 언어 로딩 흐름

```
앱 시작 (main_qt.cpp)
  └─ QSettings("Abang-All", "Abang-All").value("ui/language", "ko")
       ├─ "ko" → QTranslator 로드 없음 → 한국어 UI
       └─ "en" → QTranslator::load(":/i18n/en.qm") → installTranslator() → 영어 UI
       └─ MainWindow 생성
```

### 소스 코드 변경: tr() 래핑

`MainWindow.cpp`, `TrayWidget.cpp`의 모든 사용자 표시 문자열을 `tr()`로 감싼다.

대상:
- 페이지 제목 (`"로그"`, `"설정"`, `"USB 목록"` 등)
- 네비게이션 버튼 레이블
- 테이블 컬럼 헤더
- 버튼 텍스트 (저장, 초기화, 허용, 차단 등)
- 설정 항목 레이블
- 상태/정책 배지 텍스트 (`"허용"`, `"차단"`, `"승인 대기"` 등)
- 상세 패널 레이블
- 메시지/플레이스홀더 텍스트

대상 아님 (번역 불필요):
- 로그 원문 (Logger::Add로 들어오는 내부 로그 문자열)
- `QObject::setObjectName()` 값 (CSS 선택자용)
- 아이콘 리소스 경로

예시:
```cpp
// 이전
headerRow->addWidget(label("로그", "pageTitle"));
table->setHorizontalHeaderLabels({"시간", "이벤트", "장치", "처리 결과"});

// 이후
headerRow->addWidget(label(tr("로그"), "pageTitle"));
table->setHorizontalHeaderLabels({tr("시간"), tr("이벤트"), tr("장치"), tr("처리 결과")});
```

### 파일 구조

```
Capstone/UIQt/Assets/
  i18n/
    en.ts     ← 영어 번역 원본 (수작업 작성 후 lupdate로 유지)
    en.qm     ← lrelease로 빌드 (CMake에서 자동 생성)

ui.qrc:
  <file>i18n/en.qm</file>
```

### CMakeLists.txt 변경

```cmake
find_package(Qt5 COMPONENTS LinguistTools REQUIRED)
qt5_add_translation(QM_FILES
    Assets/i18n/en.ts
)
# QM_FILES를 qrc 대신 target_sources로 연결하거나,
# configure_file로 Assets/i18n/에 복사 후 qrc에서 참조
```

빌드 시 `en.ts` → `en.qm` 자동 컴파일되어 `.qrc`를 통해 실행파일에 임베드된다.

### 설정 UI 변경

기존 체크박스 `"프로그램 한글/영어 전환"` 제거 →  
테마 토글과 동일한 **세그먼트 선택기**로 교체:

```
언어   [ 한국어 | English ]
```

- 저장 키: `QSettings("Abang-All","Abang-All")` → `"ui/language"` → `"ko"` 또는 `"en"`
- 저장 버튼 클릭 시 언어가 변경된 경우: `QMessageBox::information(... "재시작 후 적용됩니다.")`
- 기존 `cbHangulKey` 멤버 및 `ui/languageToggleKorean` 키 제거, `langGroup` 세그먼트로 대체

### en.ts 번역 파일 (작성 대상)

`QCoreApplication::translate("MainWindow", ...)` 컨텍스트로 약 280~320개 문자열.  
주요 카테고리:

| 카테고리 | 예시 |
|---|---|
| 페이지 제목 | 로그→Log, 설정→Settings, USB 목록→USB List |
| 네비게이션 | 대시보드→Dashboard, 분석→Analytics |
| 테이블 헤더 | 장치명→Device Name, 처리 결과→Result |
| 정책 배지 | 허용→Allowed, 차단→Blocked, 승인 대기→Pending |
| 버튼 | 저장→Save, 초기화→Reset, 허용→Allow, 차단→Block |
| 설정 항목 | 위험 감지 시 알림 표시→Show alert on threat detected |
| 상태 | 연결됨→Connected, 차단됨→Blocked |

## 기능 2 — 로그 보관 기간 대시보드 연동

### 문제

`createDashboardPage()` 내 정책 요약 행에 `"30일"`이 하드코딩되어 있어,  
설정에서 보관 기간을 바꿔도 대시보드에 반영되지 않는다.

### 변경 내용

대시보드 생성 시 QSettings에서 실제 값을 읽어 표시한다:

```cpp
// MainWindow.cpp - createDashboardPage() 또는 정책 요약 구성 부분
QSettings uiSettings(QStringLiteral("Abang-All"), QStringLiteral("Abang-All"));
const int retentionDays = uiSettings.value(QStringLiteral("ui/logRetentionDays"), 30).toInt();
const QString retentionLabel = retentionDays <= 0
    ? tr("영구 보관")
    : tr("%1일").arg(retentionDays);

// 기존 하드코딩
{"로그 보관 기간", "30일", "policyValueText"},

// 변경 후
{tr("로그 보관 기간"), retentionLabel, "policyValueText"},
```

대시보드는 현재 앱 시작 시 한 번만 생성되므로, 설정 변경 후 재시작 시 올바른 값이 표시된다.  
(언어 전환도 재시작 적용이므로 타이밍이 일치한다.)

## 구현 순서

1. **CMakeLists.txt** — `Qt5::LinguistTools` 추가, `qt5_add_translation` 설정
2. **ui.qrc** — `i18n/en.qm` 항목 추가

4. **MainWindow.cpp** — 모든 사용자 표시 문자열 `tr()` 래핑
5. **TrayWidget.cpp** — 트레이 메뉴/알림 문자열 `tr()` 래핑

7. **MainWindow.cpp (대시보드)** — 로그 보관 기간 하드코딩 → QSettings 값으로 교체
8. **Assets/i18n/en.ts** — 영어 번역 파일 작성
9. **빌드 확인** — Release 빌드 성공 + 한/영 전환 동작 확인

## 비고

- `lrelease`는 Qt 설치에 포함된 도구. CMake 통합 시 별도 실행 불필요.
- 기존 `ui/languageToggleKorean` QSettings 키는 `ui/language`로 마이그레이션.  
  이전 설정 파일과의 하위 호환: `languageToggleKorean == true` → `language = "ko"` 로 읽는 변환 로직 추가.
- 로그 원문(Logger 내부 문자열)은 번역 대상에서 제외. 로그는 항상 원본 언어(한국어/영어 혼용)로 기록.
