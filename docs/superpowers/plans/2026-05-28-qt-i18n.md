# Qt i18n 한글↔영어 전환 + 로그 보관 기간 대시보드 연동 구현 플랜

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Qt6 표준 i18n을 통해 앱 UI 전체를 한국어↔영어로 전환 가능하게 하고, 로그 보관 기간 설정이 대시보드에 반영되도록 연결한다.

**Architecture:** 소스 언어는 한국어(tr() 기본값). `en.ts` 번역 파일을 `qt_add_translations`로 빌드 시 `.qm`으로 컴파일해 리소스에 임베드. 앱 시작 시 `QSettings("ui/language")`를 읽어 `"en"`이면 `QTranslator`를 로드하고 `installTranslator()`. 재시작 후 적용 방식.

**Tech Stack:** Qt6, CMake `qt_add_translations`, QTranslator, QSettings

## Task 1: CMakeLists.txt — LinguistTools + qt_add_translations

**Files:**
- Modify: `CMakeLists.txt`

- [ ] **Step 1: LinguistTools 컴포넌트 추가**

`find_package(Qt6 ...)` 줄을 찾아 `LinguistTools` 추가:

```cmake
# 기존
find_package(Qt6 REQUIRED COMPONENTS Widgets Svg)

# 변경 후
find_package(Qt6 REQUIRED COMPONENTS Widgets Svg LinguistTools)
```

- [ ] **Step 2: qt_add_translations 호출 추가**

`target_link_libraries(CapstoneQtApp ...)` 블록 바로 아래에 추가:

```cmake
    target_link_libraries(CapstoneQtApp PRIVATE
        CapstoneCore
        Qt6::Svg
        Qt6::Widgets
    )

    # ↓ 이 블록 추가
    qt_add_translations(CapstoneQtApp
        TS_FILES Capstone/UIQt/Assets/i18n/en.ts
        RESOURCE_PREFIX "/i18n"
    )
```

> `qt_add_translations`는 빌드 시 `en.ts` → `en.qm`을 자동 컴파일하고 `:/i18n/en.qm` 경로로 리소스에 임베드한다. `ui.qrc` 수동 편집 불필요.

- [ ] **Step 3: i18n 디렉터리 생성**

```powershell
New-Item -ItemType Directory -Force "Capstone\UIQt\Assets\i18n"
```

- [ ] **Step 4: 빌드 확인 (en.ts 없으면 오류 예상 — Task 2에서 생성 후 재확인)**


```cpp
    QTranslator translator;
    {
        QSettings langSettings(QStringLiteral("Abang-All"), QStringLiteral("Abang-All"));
        // 하위 호환: 기존 ui/languageToggleKorean 키도 읽는다
        QString lang = langSettings.value(QStringLiteral("ui/language"), QString()).toString();
        if (lang.isEmpty()) {
            // 이전 버전 설정 마이그레이션
            const bool wasKorean = langSettings.value(QStringLiteral("ui/languageToggleKorean"), true).toBool();

            langSettings.setValue(QStringLiteral("ui/language"), lang);
        }
        if (lang == QStringLiteral("en")) {
            if (translator.load(QStringLiteral(":/i18n/en.qm")))
                app.installTranslator(&translator);
        }
    }
    // ────────────────────────────────────────────────────────────────

    MainWindow window;
```
